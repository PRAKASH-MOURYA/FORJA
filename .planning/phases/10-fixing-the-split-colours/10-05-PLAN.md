**Circle animation:**
Use a `TweenAnimationBuilder<double>` keyed on `ValueKey(readiness?.score ?? 0)` for replay when score changes, PLUS a `_animKey` int state field incremented in `initState` (for StatefulWidget) or `useEffect` (for HookConsumerWidget) to force replay on every mount:

```dart
// For StatefulWidget version:
int _animKey = 0;
@override void initState() { super.initState(); _animKey++; }

// On the TweenAnimationBuilder:
key: ValueKey(_animKey),
tween: Tween<double>(begin: 0, end: (readiness?.score ?? 0).toDouble()),
duration: const Duration(milliseconds: 800),
curve: Curves.easeOut,
builder: (context, value, _) {
  final displayScore = value.round();
  final zoneColor = _zoneColor(displayScore);
  final zoneLabel = _zoneLabel(displayScore);
  return AnimatedProgressRing(
    progress: value / 100,
    size: ProgressRingSize.lg,
    progressGradient: LinearGradient(colors: [zoneColor, zoneColor]),
    center: Column(
      mainAxisSize: MainAxisSize.min,
      children: [
        Text('$displayScore', style: AppTextStyles.h2(zoneColor)),
        Text(zoneLabel, style: AppTextStyles.micro(context.appTextSecondary)),
      ],
    ),
  );
}
```

**Zone helpers (private static methods):**
```dart
static Color _zoneColor(int score) {
  if (score <= 40) return AppColors.danger;
  if (score <= 70) return AppColors.warning;
  return AppColors.positive;
}
static String _zoneLabel(int score) {
  if (score <= 40) return 'Recover';
  if (score <= 70) return 'Moderate';
  return 'Ready';
}
```

If `readiness` is null: show a neutral ring (progress: 0, label: '–').
