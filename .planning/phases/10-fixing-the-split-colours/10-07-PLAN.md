**Step 2 — Replacement rules:**
- `AppColors.bg` (as a color value, e.g. `backgroundColor: AppColors.bg`) → `context.appBg`
- `AppColors.bgCard` → `context.appBgCard`
- `AppColors.bgElevated` → `context.appBgElevated`
- `AppColors.textPrimary` → `context.appTextPrimary`
- `AppColors.textSecondary` → `context.appTextSecondary`
- `AppColors.textTertiary` → `context.appTextTertiary`
- `AppColors.border` → `context.appBorder`
- `isDark ? AppColors.bg : AppColors.bgLight` (verbose ternary pattern) → `context.appBg`

**DO NOT change:**
- `AppColors.accent` — intentionally same in both modes (white/black handled by appAccent but accent is used for brand actions)
- `AppColors.positive`, `AppColors.danger`, `AppColors.warning` — semantic colors, same in both modes
- Any `AppColors.` reference inside a Color constant definition in theme.dart itself
