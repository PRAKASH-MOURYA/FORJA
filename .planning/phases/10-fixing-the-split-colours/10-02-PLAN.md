bool get allResolved => exercises.isNotEmpty &&

**Part B — WorkoutNotifier changes:**

In `startWorkout()`, replace `currentExerciseIndex: 0` with `activeExerciseId: exercises.isNotEmpty ? exercises.first.id : null, skippedExerciseIds: const {}`.

Add `jumpToExercise(String exerciseId)`:
```dart
void jumpToExercise(String exerciseId) {
  if (state.exercises.any((e) => e.id == exerciseId)) {
    state = state.copyWith(activeExerciseId: exerciseId);
  }
}
```

Add `markSkipped(String exerciseId)`:
```dart
void markSkipped(String exerciseId) {
  final updated = {...state.skippedExerciseIds, exerciseId};
  state = state.copyWith(skippedExerciseIds: updated);
}
```

Update `nextExercise()` to advance to the next exercise by index (find current index in exercises list, increment, set activeExerciseId). If already at last, do nothing:
```dart
void nextExercise() {
  final idx = state.exercises.indexWhere((e) => e.id == state.activeExerciseId);
  if (idx < state.exercises.length - 1) {
    state = state.copyWith(activeExerciseId: state.exercises[idx + 1].id);
  }
}
```
